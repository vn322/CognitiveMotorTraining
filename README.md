# 📘  Руководство  использования
## CognitiveMotorTraining — оценка когнитивно-моторной подготовленности

---

## 🔹 1. Назначение программы

Программа **CognitiveMotorTraining** предназначена для объективной оценки **когнитивно-моторных способностей** спортсменов и специалистов, требующих быстрой реакции, принятия решений в условиях неопределённости и адаптации к динамически меняющейся обстановке.

Применима для:
- единоборств (бокс, ММА, фехтование),
- командных игр (футбол, баскетбол — вратари, защитники),
- экстремальных видов спорта (автоспорт, горнолыжный спорт),
- фиджитал активностей.

## 🔹 3. Описание тестов

Всего **10 тестов**, объединённых в 4 группы:

### 🟢 3.1. Базовые реакции

| Тест | Описание | Показатели |
|------|----------|------------|
| **Simple Reaction** | Красный круг → касание в центре | `Total_RT_ms`, `Latency_ms`, `Movement_ms` |
| **Choice: Simple** | Круг + дистрактор (30%); совпадает с образцом | `Correct`, `Timing_error_ms` |
| **Choice: Complex** | Выбор из 2 цветов + 2 форм | `CD`, `Joint` |
| **Choice: Sequence** | Последовательное касание 2 стимулов | `Sequence_success`, `Update_latency_ms` |

### 🟡 3.2. Защитные и динамические реакции

| Тест | Описание | Показатели |
|------|----------|------------|
| **Defense Reaction** | Защита уклоном при сигнале в виде креста на голове или плечах имитирующих угрозу | **`IT` — Индекс избегания** |
| **Moving Object** | Касание зоны в момент пересечения стимулом | `Timing_error_ms`, `Prediction_error_px` |
| **Perturbation Recovery** | Неожиданное изменение скорости стимула | `AD`, `Adaptation_rate` |

### 🔵 3.3. Слежение

| Тест | Описание | Показатели |
|------|----------|------------|
| **Tracking Reaction** | Плавное слежение за синусоидой/спиралью | `Tracking_error_mm`, `Coverage_%` |

### 🟣 3.4. Комбинированные (интегративные) реакции

| Тест | Описание | Особенности |
|------|----------|-------------|
| **Combined Reaction: Selection + Tracking** | Образец → 2 движущихся стимула (цель + дистрактор); касание цели | **RT + выбор + слежение** |
| **Combined Reaction: Dynamic Switch** | То же + **2 смены ролей** (цель ↔ дистрактор) | **RT + выбор + слежение + адаптация + торможение** |

> ✅ **Комбинированные тесты** — главный диагностический инструмент. Они имитируют реальные условия: информация неполная, помехи есть, решения принимаются в движении.

## 🔹 4. Ключевые расчётные метрики

Все метрики вычисляются автоматически и выводятся в аналитическом отчёте.

### 📊 4.1. Базовые метрики

| Метрика | Формула | Норма | Интерпретация |
|---------|---------|-------|---------------|
| **CD (Когнитивная доля)** | `Latency_ms / Total_RT_ms` | 0.20–0.35 | Доля времени на принятие решения. <0.15 → импульсивность. |
| **IT (Индекс избегания)** | `Успех в Defense Reaction` | >0.70 | Способность избегать угрозы. |
| **AD (Адаптивный дефицит)** | `1 − Успех в Perturbation Recovery` | <0.30 | Неспособность корректировать движение при неожиданности. |
| **ME (Моторная экономичность)** | Среднее `Movement_economy` | >0.85 | Прямолинейность траектории. <0.85 → избыточные движения. |

### 📊 4.2. Продвинутые метрики

| Метрика | Формула | Норма | Интерпретация |
|---------|---------|-------|---------------|
| **TA (Тактическая активность)** | `Доля RT < 500 мс` | 0.3–0.6 | Склонность к быстрым, но рискованным решениям. |
| **LD (Латеральный дисбаланс)** | `\|RTₗ − RTᵣ\| / ((RTₗ + RTᵣ)/2)` | <0.20 | Асимметрия левой и правой руки. >0.3 → явная доминантность. |
| **ZG (Тактическая гибкость)** | `−Σ pᵢ · ln(pᵢ)` (энтропия успехов по тестам) | 1.5–2.5 | Разнообразие стратегий. <1.2 → «монозонная» тактика. |

> 💡 **Пример**:  
> - `CD = 0.12`, `IT = 0.43`, `AD = 0.95` → **импульсивный, нетренированный тактически** спортсмен.  
> - `CD = 0.28`, `IT = 0.82`, `AD = 0.15` → **зрелая, адаптивная тактика**.

## 🔹 5. Проведение тестирования

### 📋 5.1. Этапы

1. **Подготовка**  
   - Запустите `main.exe`  
   - Убедитесь, что скелет (жёлтый — правая рука, зелёный — левая) отображается  
   - Нажмите `⏹ Abort`, если поза некорректна

2. **Запуск теста**  
   - Выберите тест из списка  
   - Нажмите соответствующую кнопку  
   - Дождитесь сигнала «Start» (красный) → начинайте

3. **Выполнение**  
   - Следуйте визуальным подсказкам:  
     - 🔴 **Красный** — «Стоп» (не касайтесь)  
     - 🟢 **Зелёный** — «Go» (можно касаться)  
     - ❗ **Восклицательный знак** — помеха (не касайтесь!)  
   - Используйте **любую руку** — программа фиксирует выбор

4. **Завершение**  
   - После 10–14 попыток появится «Stop»  
   - Нажмите `💾 Export + Report` для сохранения отчёта  
   - автоматически создадутся:  
     - `report_ГГГГ_ММ_ДД_ЧЧ_ММ.csv`  
     - `report_ГГГГ_ММ_ДД_ЧЧ_ММ_analysis.pdf`

## 🔹 6. Анализ отчёта

Отчёт состоит из **6 разделов**:

### 📑 6.1. Ключевые расчётные метрики  
→ Таблица с CD, IT, AD, ME, LD, ZG + интерпретация.

### 📑 6.2. Латеральный профиль  
→ Сравнение левой и правой руки: RT, успех, дельта.

### 📑 6.3. Активность в различных условиях (тестах)  
→ Успех, RT, CD по каждому тесту. **Обратите внимание на комбинированные реакции** — они наиболее информативны.

### 📑 6.4. Пространственное распределение активности (3×3)  
→ Карта «Верхняя/Средняя/Нижняя» × «Левая/Центр/Правая»:  
- Какая зона «сильная»?  
- Какой рукой чаще действуют?  
- Где RT выше? (например, «Верхняя Левая» — сложнее координировать подъём левой руки)

### 📑 6.5. Анализ слежения  
→ Только для `Tracking Reaction`:  
- `Средняя ошибка слежения` < 50 мм → хороший контроль  
- `σ > 30` → нестабильность  
- `> 80 мм` → системное отставание

### 📑 6.6. Тактический диагноз и рекомендации  
→ Персонализированный вывод и 2–4 конкретные рекомендации.  
Пример:  
> *«Низкий уровень торможения: трудности с подавлением импульсивных реакций при помехах»*  
> → **Рекомендация**: *«Ввести режим “ложные старты”.*

## 🔹 8. Частые ошибки и решения

| Проблема | Причина | Решение |
|---------|---------|---------|
| ❌ Скелет не отображается | Слабое освещение / фон сливается с одеждой | Наденьте контрастную одежду, включите лампу спереди |
| ❌ «Tracking Reaction» не запускается | Отсутствует `pose_landmark_cpu.binarypb` | Убедитесь, что файл в корне проекта перед сборкой |
| ❌ PDF не создаётся | Нет `DejaVuSans.ttf` | Скачайте шрифт и положите рядом с `main.exe` |
| ❌ Все RT ≈ 0 мс | Антиципация («угадывание») | Увеличьте timeout в `config/default.json` → `"simple_reaction": {"trials": 14, "timeout": 1.5}` |

## 🔹 9. Настройка под задачу

Конфигурация хранится в `config/default.json`. Пример:

```json
{
  "camera": {"index": 0, "flip_horizontal": true},
  "simple_reaction": {"trials": 10, "timeout": 1.2},
  "defense_reaction": {"trials": 12, "distractor_prob": 0.5},
  "combined_reaction": {"trials": 20}
}
```

| Параметр | Описание |
|---------|----------|
| `timeout` | Таймаут в секундах (по умолчанию: 2.0 для простой, 5.0 для комбинированной) |
| `distractor_prob` | Вероятность появления дистрактора (0.0–1.0) |
| `trials` | Количество попыток |

> 💡 Для **диагностической точности** рекомендуется ≥12 попыток на тест.
